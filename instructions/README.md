## 🚀 Быстрый старт

### 1. Запуск проекта
```bash
# Переход в директорию проектов
cd projects

# Применение миграций
python manage.py migrate

# Создание суперпользователя (при необходимости)
python manage.py createsuperuser

# Запуск dev-сервера
python manage.py runserver
```

### 2. Наполнение базы данных реальным меню Бункермуз
```bash
python projects/manage.py seed_bunkermuz
```
Команда загружает 58 оригинальных позиций меню с реальными фото (CDN ChoiceQR), ингредиентами, ценами, а также коктейльную карту, кальяны, афишу арт-клуба и отзывы.

### 3. Запуск тестов
```bash
python projects/manage.py test main
```
