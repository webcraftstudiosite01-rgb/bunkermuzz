# Руководство по разработке на Django (Django Guidelines)

## 1. Модели (Models)

- **Явные `verbose_name` и `verbose_name_plural`:** Все модели и поля должны иметь русскоязычные человекочитаемые наименования.
- **Строковое представление:** Каждая модель обязана реализовывать метод `__str__()`.
- **Индексы:** Для полей, участвующих в частых фильтрациях, сортировках или внешних ключах (`ForeignKey`), используйте `db_index=True` или `Meta.indexes`.
- **Временные метки:** Для сущностей рекомендуется добавлять поля аудита:
  ```python
  created_at = models.DateTimeField(auto_now_add=True, verbose_name="Дата создания")
  updated_at = models.DateTimeField(auto_now=True, verbose_name="Дата обновления")
  ```

---

## 2. Представления (Views) и логика

- **"Толстые" модели / сервисы, "тонкие" представления:**
  - Бизнес-логику следует выносить в сервисный слой (например, `services.py`), кастомные `QuerySet` / `Manager`, либо методы моделей.
  - Вьюхи должны отвечать только за валидацию запроса, вызов сервиса и возврат ответа/рендеринг шаблона.
- **Оптимизация ORM:**
  - Всегда используйте `select_related()` для связей OneToOne и ForeignKey.
  - Всегда используйте `prefetch_related()` для связей ManyToMany и обратных ForeignKey.
  - Используйте `only()` или `defer()`, если в таблице присутствуют тяжелые текстовые/бинарные поля.
  - Избегайте проблемы N+1 запросов.

---

## 3. Шаблоны и статика

- Все базовые страницы должны наследоваться от `templates/base.html`:
  ```django
  {% extends 'base.html' %}
  {% block title %}Заголовок страницы{% endblock %}
  {% block content %}...{% endblock %}
  ```
- Статические файлы подключаются через `{% load static %}` и `{% static 'path/to/file' %}`.
- Запрещено использовать жестко закодированные абсолютные ссылки на локальные статические файлы.
- URL-адреса генерируются через тег `{% url 'app_name:view_name' %}`.

---

## 4. Безопасность и конфигурация

- **Секретные ключи:** Никогда не хранить пароли, API-ключи и `SECRET_KEY` в репозитории в открытом виде.
- **Режим отладки:** `DEBUG = False` для любых публичных / продакшн сред.
- **CSRF:** Все формы POST должны содержать токен `{% csrf_token %}`.
- **XSS:** Никогда не использовать фильтр `|safe` для пользовательского непроверенного контента.
