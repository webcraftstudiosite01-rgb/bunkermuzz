# Стандарты кодирования (Coding Standards)

## Общие принципы

1. **Читаемость превыше краткости:** Код пишется для людей, а исполняется машиной.
2. **Явное лучше неявного (The Zen of Python):** Избегайте "магических" неявных вызовов и скрытых состояний.
3. **DRY (Don't Repeat Yourself):** Выносите повторяющуюся логику в сервисные функции, миксины или утилиты.
4. **KISS (Keep It Simple, Stupid):** Не создавайте избыточных абстракций, пока в них нет реальной потребности.

---

## Стандарты Python

### 1. Соответствие PEP 8
- Длина строки: максимум 88–100 символов.
- Отступы: 4 пробела (никаких табов).
- Именование:
  - Классы: `PascalCase` (`UserProfile`, `ProjectInfoAdmin`)
  - Функции и методы: `snake_case` (`get_user_info()`, `calculate_total()`)
  - Переменные: `snake_case` (`item_count`, `is_active`)
  - Константы: `UPPER_SNAKE_CASE` (`DEFAULT_PAGE_SIZE`, `MAX_RETRIES`)
  - Модули и пакеты: короткие имена в нижнем регистре (`models.py`, `views.py`)

### 2. Типизация (Type Hints)
- Для всех публичных функций, методов и сервисов обязательно указание аннотаций типов:
  ```python
  def get_active_projects(limit: int = 10) -> list[ProjectInfo]:
      ...
  ```
- Для опциональных значений используйте `T | None` (Python 3.10+).

### 3. Форматирование импортов
Импорты должны быть сгруппированы в три блока с разделением пустой строкой:
1. Стандартная библиотека Python (`os`, `sys`, `pathlib`).
2. Сторонние библиотеки и фреймворки (`django`, `requests`).
3. Локальные модули проекта (`from .models import ...`, `from main.services import ...`).

## Стандарты HTML / CSS / JS

1. **HTML:**
   - Валидная разметка HTML5.
   - Семантические теги: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`.
   - Обязательное экранирование данных и использование шаблонизатора Django (`{{ variable }}`).
   - Теги `alt` для всех изображений.

2. **CSS:**
   - Использование CSS Custom Properties (переменных) для единой палитры и отступов.
   - Mobile-first адаптивность.

3. **JavaScript:**
   - Современный синтаксис ES6+ (`const`, `let`, стрелочные функции, `async/await`).
   - Инициализация логики после события `DOMContentLoaded`.
